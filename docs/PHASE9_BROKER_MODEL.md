# Phase 9 — Broker Model Reconciliation

## Objective

Reproduce the valuation quantities visible in the uploaded Paytm Money screenshots without treating them as historical trading results.

Paytm Money publicly describes its platform as supporting multi-leg F&O strategy construction and option-chain/strategy analysis. The screenshot-specific values below are used as calibration data, not as generic undocumented claims about the platform.

## Calibrated inputs from the screenshot

- Spot: 23,329
- Weekly future: 23,436.90
- Monthly future: 23,510.00
- Weekly expiry: 06-Oct-2026
- Monthly expiry: 27-Oct-2026
- Lot size: 65
- Entry net premium: ₹180.75/point
- Intrinsic Value: ₹12,100
- Time Value: -₹351
- Delta: -0.041
- Vega: -0.67
- Gamma: approximately 0
- 1 SD: 303 points
- Breakevens: 23,448 and 23,487
- POP: 96%

## Why Black-76

The screenshot supplies a futures price for each expiry. Black-76 is therefore a natural calibration model for options written on futures/forwards. The research does not assert that Paytm Money uses Black-76 internally; it tests whether a Black-76 calibration can reproduce the displayed values.

## Results from the calibration

Using the screenshot premiums:

- 23,350 monthly PE: ₹226.60
- 23,250 monthly CE: ₹451.00
- 23,450 weekly PE: ₹179.00
- 23,350 weekly CE: ₹222.65

and treating 23-Sep-2026 as the screenshot valuation date, the individual implied volatilities are approximately:

- Monthly 23,350 PE: 10.51%
- Monthly 23,250 CE: 10.66%
- Weekly 23,450 PE: 9.77%
- Weekly 23,350 CE: 9.98%

The calibrated portfolio delta is about -0.041 and the portfolio vega is about -0.67 per 1 vol point, closely matching the screenshot.

The reconstructed intrinsic value is ₹12,103, versus the displayed ₹12,100. This is an independent consistency check using the separate weekly/monthly futures.

The screenshot's POP of 96% is also approximately reproducible from the displayed breakevens and 1-SD value of 303 points: treating the terminal distribution as normal around spot 23,329 gives about 95.4% probability outside the interval 23,448–23,487, consistent with the rounded displayed 96%.

## Important limitations

1. The exact Paytm Money internal model has not been reverse-engineered from source code. Black-76 is a research replication hypothesis.
2. The screenshot valuation date is inferred as 23-Sep-2026 from the current project date and the October 2026 expiry labels. The calibration script exposes the date as a constant so it can be changed if a timestamped screenshot date is confirmed.
3. The broker's exact theta/decay convention, volatility surface interpolation, discounting, and POP methodology are not fully identified from the screenshots alone.
4. The payoff curve generated by this script is a broker-style approximation, not a proof of exact platform replication.
